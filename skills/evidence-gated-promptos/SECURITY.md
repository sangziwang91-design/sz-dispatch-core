# Security Policy

This repository contains instructions and templates, not credentials or a hosted service.

Do not submit API keys, private repository contents, patient information, personal addresses, unpublished research data, or confidential tool receipts in issues or pull requests.

Report a security concern privately through the repository owner's GitHub profile contact path. Include the affected file, reproduction conditions, potential impact, and the minimum evidence needed to verify the report.

The skill must never treat publication, sending, deletion, purchasing, permission changes, or production writes as implicitly authorized.
